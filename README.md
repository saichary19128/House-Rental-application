# 🏠 SmartRent – House Rental Application

SmartRent is a full-stack MERN-based house rental platform that connects tenants and property owners through a secure and user-friendly system. The application allows users to browse rental properties, manage bookings, and handle property listings efficiently.

---

## 🚀 Features

### 👤 Tenant Features
- User Registration & Login
- Browse Rental Properties
- Search & Filter Listings
- Add Properties to Favorites
- Book Rental Properties
- View Booking History

### 🏡 Host Features
- Add New Property Listings
- Edit Property Details
- Delete Property Listings
- Manage Property Bookings

### 🔒 Security Features
- JWT Authentication
- Password Encryption
- Protected Routes
- Role-Based Access Control (RBAC)

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/smartrent.git
```

### 2️⃣ Navigate to Project Folder

```bash
cd smartrent
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Setup Environment Variables

Create a `.env` file in the root directory and add:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

---

## ▶️ Run the Application

```bash
npm start
```

or

```bash
nodemon app.js
```

Application runs on:

```bash
http://localhost:5000
```
